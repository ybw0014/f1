Hero

I'm Bowen Yao, a Minecraft plugin developer. I build plugins and web tools, with an interest in making Slimefun better.

About

This is a portfolio project. Much of my development work centers on Minecraft, especially plugins that extend what a server can do. I also build tools outside the game, where a browser can be a useful place to look up a recipe or find an explanation before returning to play.

I maintain Minecraft plugin projects under the GuizhanCraft organization and work with SlimefunGuguProject, the Slimefun Simplified Chinese translation group. This side of open-source work matters to me because being able to read an explanation in a familiar language changes how approachable a plugin is. Working on documentation alongside the software gives me a reason to think about what a player needs explained.

Showcase

FastMachines

Got tired of putting recipes in shape? Fast machines turn all recipes to shapeless, allowing players to deal with ingredient type and amount only. Go to FastMachines repository

  • Supports vanilla Minecraft crafting recipes and furnace recipes.
  • Supports most standard Slimefun recipes.
  • Supports recipes from famous Slimefun addons.

SlimefunTranslation

SlimefunTranslation allows players to see items in their own language without changing the original item on server. Go to SlimefunTranslation repository

slimefun-helper

My slimefun-helper project is a web-based Slimefun calculator with item ID and recipe lookups. I'm interested in putting those functions in a browser so that looking up an item and working with its recipe can happen in the same place, outside the game. Visit Slimefun Helper.
